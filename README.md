# Python from Zero: companion files

These are the companion files for the book *Python from Zero: A friendly, hands-on guide
to writing your first real programs* by Mathew Kariuki.

- `notebooks/` has one Jupyter notebook per chapter, already run so you can see the output.
- `programs/` has the programs you run as files, including the Chapter 17 Shelter Manager.
- `data/` has the Sunny Paws data files used in the book.
- `exercise-solutions.pdf` has worked solutions to every exercise.
- `requirements.txt` lists the extra Python packages the book uses.

## Download

Click the green **Code** button above, then **Download ZIP**. Unzip it somewhere easy
to find, such as `Documents/python-from-zero`, keeping `data/`, `notebooks/` and
`programs/` side by side. Then follow Chapter 1, section "Getting the book files".

Sunny Paws and all of its animals, people and data are fictional.
